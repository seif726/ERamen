# ERamen 🍜

Modern Japanese ramen restaurant website with authentication system, shopping cart, and responsive design.

## Features
- User Authentication (Sign Up / Login)
- Password Encryption
- Shopping Cart System
- Google Sheets Integration
- Responsive UI Design
- Modern Japanese Restaurant Theme

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Google Apps Script
- Google Sheets API
